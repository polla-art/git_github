# Atividade Avaliativa — Fluxo Profissional com Git e GitHub

## Desenvolvimento de Sistemas

Esta atividade simula um fluxo profissional de desenvolvimento utilizando Git e GitHub.

O objetivo é praticar a criação de branches, commits, Pull Requests, revisão de código e resolução de conflitos.

## Design Profissional

A organização do projeto deve priorizar clareza, consistência e facilidade de manutenção, aplicando princípios de organização visual e comunicação eficiente.

## Fluxo de Trabalho

- Criar uma branch para cada integrante.
- Realizar alterações de forma individual.
- Registrar as alterações por meio de commits.
- Enviar as branches para o GitHub.
- Criar Pull Requests para revisão.
- Realizar revisão por outro integrante da equipe.
- Resolver conflitos quando necessário.
